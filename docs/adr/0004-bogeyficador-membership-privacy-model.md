# Keep Bogeyficador membership private and staff-managed

Bogeyficador will check active MBQB membership from a restricted Payload collection managed by Admins and Validation Managers, not from public accounts or a member profile model. Public results stay generic, analytics remain aggregate-only without raw RUT storage, and active membership is a manual indefinite staff-managed status so version 1 avoids implying payments, identity verification, or self-service membership workflows.
